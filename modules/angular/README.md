## 1. Introduction
This module provides the necessary tools, scripts, files and templates to work with Angular projects.

The Angular project is:
- Standalone components based project (no NgModules)
- SCSS based styling
- Runtime configuration (config.json) based project
- No SSR (Server Side Rendering) and no Zoneless project
- Zone.js based change detection (not zoneless)
- Angular v20+

## 2. Scope
Compared to default Angular CLI project, this module provides additional files and configurations to enhance the development experience and maintain code quality such as:

- Angular FS (extra to default Angular CLI project)
- VS Code - settings.json, extensions.json
- Prettier - .prettierrc, .prettierignore
- ESLint - eslint.config.js
- EditorConfig - .editorconfig
- TS config - tsconfig.app.json, tsconfig.spec.json
- API Contract (OpenAPI Swagger) - ./contracts/README.md
- Testing - package.json scripts for testing
- Production configuration - package.json scripts for production build
- NPM audit & dependabot - dependabot.yml, ci-npm-audit.yml both in base repo `.github/workflows` folder
- testing - uses Karma + Jasmine for unit and integration testing

## 4. Pre-requisites

The pre-sequisites are validated automatically. If not meet, script will stop and provide instructions.

1. Module `Bootstrap` executed successfully
2. Module `Scaffold` executed successfully
3. Install Google Chrome (Optional) [Link](#41-install-google-chrome-optional)

### 4.1 Install Google Chrome (Optional)

The Angular module validates automatically installation of Google Chrome browser. If not installed, follow the steps below to install it.

Validate installation
```bash
google-chrome --version
```
If not installed, install Google Chrome:

Download source: https://www.google.com/chrome/

```plaintext
1. Click the "Download Chrome" button.
2. Select the `.deb` package for Debian/Ubuntu.
```

Install Google Chrome using the downloaded `.deb` package:

```bash
cd ~/Downloads
sudo dpkg -i google-chrome-stable_current_amd64.deb
sudo apt install -f  # Fix any dependency issues
```

Validate the installation:

```bash
google-chrome --version
```
